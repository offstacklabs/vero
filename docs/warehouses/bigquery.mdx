# Google BigQuery

Vero natively supports Google BigQuery as its primary enterprise data warehouse driver.

---

## Configuration

In your `.vero/config.yaml`:

```yaml
version: "1.0"
database:
  dialect: "bigquery"
  connection_string: "bigquery://your-gcp-project-id/your_analytics_dataset"
```

## Authentication

Vero leverages standard Google Cloud **Application Default Credentials (ADC)** or service account keys:

```bash
# Authenticate via gcloud CLI on local machine:
gcloud auth application-default login

# Or set service account key environment variable:
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account.json"
```

---

## Native Dry-Run Cost Guard ($0 Compute Charge)

Before executing any query against BigQuery, Vero automatically executes a native dry-run:

```python
job_config = bigquery.QueryJobConfig(dry_run=True, use_query_cache=False)
query_job = client.query(sql, job_config=job_config)
total_bytes = query_job.total_bytes_processed
```

* **Cost**: Exactly **$0.00**. BigQuery parses, optimizes, and estimates the scan volume without charging compute.
* **Cost Formula**: `(total_bytes / 1 TB) * $6.25`.
* **Safety Limit**: If the estimated scan exceeds `max_bytes_scanned` (default: 10 GB), Vero blocks the query and requests partition filters.
