# Vero Enterprise Edition 🏢

Vero Enterprise Edition (`vero-ee`) is the commercial distribution of Vero, designed for enterprise deployments requiring enterprise identity management, regulatory compliance, and multi-tenant security.

* **Open-Source Repository**: [github.com/offstacklabs/vero](https://github.com/offstacklabs/vero) (Apache 2.0)
* **Commercial Enterprise Repository**: [github.com/offstacklabs/vero-enterprise](https://github.com/offstacklabs/vero-enterprise) (Proprietary)

---

## Enterprise Feature Matrix

| Capability | Open-Source Core | Enterprise Edition |
| :--- | :---: | :---: |
| **Warehouse Drivers** | DuckDB, SQLite, PostgreSQL | + Google BigQuery, Snowflake |
| **Identity & Access** | Local Single Developer | Corporate OIDC SSO (Okta, Azure AD, OneLogin) |
| **Directory Group Mapping** | ❌ | Automatically maps IdP groups to roles & domains |
| **Multi-Tenancy** | Single namespace (`global`) | Domain-scoped RBAC (`allowed_domains`) |
| **Data Governance** | ❌ | Automated Column-Level PII Masking & Hashing |
| **Performance Caching** | Embedded Semantic Cache | Embedded Semantic Cache + Centralized DB |
| **Automated Diagnostics** | ❌ | Automated Root Cause Analysis (RCA) Deviation Engine |
| **Support & SLAs** | Community Support | 24/7 Dedicated SLA & SOC 2 Compliance |
